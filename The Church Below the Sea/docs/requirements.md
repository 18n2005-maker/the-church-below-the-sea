# TOEIC Learning Journey — 機能要件

## 1. 概要

**TOEIC Learning Journey** は、単に「問題に正解できたか」だけではなく、**英語を本当に理解できるようになったか**を記録・管理するTOEIC学習アプリである。

### 解決したい課題

同じTOEIC問題を繰り返し解いていると、問題や答えを覚えてしまい、

> 「正解できるようになった」＝「英語を理解できるようになった」

とは限らない。

そこで本アプリでは、以下を分離して記録する。

* 問題に正解したか
* 音声を聞き取れたか
* 英文の意味を理解できたか
* 時間を空けても理解できるか

### 基本コンセプト

> **正解 ≠ 習熟**

問題に正解しただけでは、Masterとは判定しない。

# 2. 対象範囲

## 2.1 対象ユーザー

以下のようなTOEIC学習者を対象とする。

* TOEIC問題を繰り返し学習している
* 自分の本当の弱点を知りたい
* 「答えを覚えただけ」と「本当に理解した」を区別したい
* 現在のスコアから目標スコアまでの進捗を確認したい

## 2.2 対応Part

初期対応：

* Part 2
* Part 3
* Part 4

# 4. 学習機能

## F-01 — Part選択

**優先度：Must**

### 概要

学習するTOEIC Partを選択できる。

### 要件

* 対応しているPartを表示する
* Partを選択できる
* 選択したPartの学習画面へ遷移する

### 完了条件

* [ ] Part選択画面が表示される
* [ ] 対応Partを選択できる
* [ ] 選択したPartの正しい学習画面が開く

---

## F-02 — 問題表示

**優先度：Must**

### 概要

選択したPartの問題を表示する。

### 要件

* 問題文を表示する
* 必要に応じて選択肢を表示する
* リスニング問題では音声再生機能を表示する
* 必要に応じて画像などの補足情報を表示する

### 完了条件

* [ ] 問題が正しく表示される
* [ ] 選択肢を選択できる
* [ ] リスニング音声を再生できる
* [ ] 回答を確定できる

---

## F-03 — 正誤記録

**優先度：Must**

### 概要

問題に正解したか、不正解だったかを記録する。

### 要件

* `correct` / `incorrect` を記録する
* 問題IDと結果を紐付ける
* ブラウザに結果を保存する

### 完了条件

* [ ] 正解が記録される
* [ ] 不正解が記録される
* [ ] 正しい問題IDと紐付く
* [ ] ページを再読み込みしても記録が残る

# 5. リスニング理解度

## F-04 — 聞き取り記録

**優先度：Must**

### 概要

リスニング問題について、音声を実際に聞き取れたかを記録する。

### 選択肢

* 聞き取れた
* 聞き取れなかった

### 重要事項

**正解したかどうかとは別に記録する。**

例えば、

> 正解：○
> 聞き取り：×

の場合、問題には正解していてもMasterにはならない。

### 完了条件

* [ ] 「聞き取れた」を選択できる
* [ ] 「聞き取れなかった」を選択できる
* [ ] 正誤結果とは別に保存される
* [ ] 正解しただけでは「聞き取れた」にはならない

---

## F-05 — 聞き取れなかった原因

**優先度：Should**

### 概要

音声を聞き取れなかった場合、その原因を記録する。

### 原因の例

* 単語が分からなかった
* 発音が聞き取れなかった
* 音のつながりが分からなかった
* 音声が速かった
* 文を途中で見失った
* 聞き取れたが意味が分からなかった

### 完了条件

* [ ] 聞き取れなかった場合に原因を選択できる
* [ ] 複数の原因を選択できる
* [ ] 選択した原因が保存される

# 7. 習熟度管理

## F-07 — 学習ステータス

**優先度：Must**

### ステータス

| ステータス      | 意味            |
| ---------- | ------------- |
| `NEW`      | まだ学習していない     |
| `LEARNING` | 学習中・まだ定着していない |
| `MASTERED` | 十分に理解・定着している  |
| `RETIRED`  | 長期間の定着を確認済み   |

### 完了条件

* [ ] すべての問題に学習ステータスがある
* [ ] 未学習問題は `NEW` から開始する
* [ ] Master条件を満たさない問題は `LEARNING` になる
* [ ] Master条件を満たした問題は `MASTERED` になる
* [ ] ステータスが保存される

---

## F-08 — Master判定

**優先度：Must**

### 概要

問題に正解しただけではMasterにしない。

### リスニング問題のMaster条件

以下をすべて満たす。

1. 正解する
2. 音声を聞き取れる
3. 英文の意味を理解できる

### リーディング問題のMaster条件

1. 正解する
2. 英文の意味を理解できる

### 完了条件

* [ ] 正解しただけではMasterにならない
* [ ] リスニングでは聞き取り成功が必要
* [ ] 意味理解成功が必要
* [ ] 条件を満たさない場合は `LEARNING` のままになる

---

## F-09 — 期間を空けた再確認

**優先度：Must**

### 概要

一度理解できただけでは完全なMasterとせず、一定期間後に再確認する。

### 例

text
初回学習
  ↓
1日後
  ↓
3日後
  ↓
7日後
  ↓
14日後
  ↓
30日後


### 完了条件

* [ ] 次回確認日を保存できる
* [ ] 確認日になった問題を再確認できる
* [ ] 再確認に成功すると次回確認日を更新できる
* [ ] 再確認に失敗するとMaster扱いを維持しない

---

## F-10 — Masterからの降格

**優先度：Must**

### 概要

Masterになった問題でも、時間を空けて再確認した際に理解できなければ `LEARNING` に戻す。

### 完了条件

* [ ] Master問題を再確認できる
* [ ] 再確認に失敗すると `LEARNING` に戻る
* [ ] 過去の学習履歴は削除しない

---

## F-11 — RETIRED

**優先度：Future**

### 概要

長期間にわたって理解が維持できた問題を通常の復習対象から外す。

### 完了条件

* [ ] 定めた条件を満たした問題を `RETIRED` にできる
* [ ] 通常のReview対象から除外される
* [ ] 学習履歴からは確認できる

# 8. 復習機能

### 重要事項

* 問題文
* 音声
* 画像
* その他の公式コンテンツ

### 完了条件

* [ ] 模試の記録を作成できる
* [ ] 問題集・テストの識別情報を記録できる
* [ ] 実施日を記録できる
* [ ] 公式問題のコンテンツ自体はアプリに収録しない
